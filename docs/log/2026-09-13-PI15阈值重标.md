# 2026-09-13 PI-15 门禁阈值重标（A/A 噪声带改善 3.7×）

## 动机
PI-15 的阈值规则是"**只有超过同档两槽都能测出来的差别**才允许判失败"，因此
阈值必须**按本机 A/A 现测**标定，且标定用的配对数 n 必须与门禁一致
（SE ∝ 1/√n）。本轮新增了两处遥测（report v3 心跳/诊断、std 档背压 n/max），
且距上次标定（2026-09-11，n=25 → 0.85%）已隔两日多轮改动，故重标。

## 标定（`bench.py telemetry-check --aa`）
口径：**同进程交替**、同档两槽（std vs std2）、config=h264-gpu、window=3000、
**n=25 对、inner=3**（与门禁完全同参）。

| 量 | 值 |
|---|---|
| 均值偏差 | **+0.072%** |
| 中位偏差 | +0.043% |
| \|Δ\|p50 | 0.150% |
| **\|Δ\|p95** | **0.484%** |
| max\|Δ\| | 1.223% |
| sd / SE | 0.366% / **0.073%** |

规则（`_limit_from_band`，写死不拍脑袋）：`|均值| + 3×SE` 上取整到 0.05%、
下限 0.30% ⇒ `0.072 + 0.219 = 0.291 → `**0.30%**；full = 4×std ⇒ **1.20%**。

## 新旧对比（这是本轮真正拿到的东西）

| 项 | 2026-09-11 标定 | **2026-09-13 标定** |
|---|---|---|
| A/A \|Δ\|p95 | 1.8% | **0.484%（改善 3.7×）** |
| 均值偏差 / SE | −0.179% / 0.211% | **+0.072% / 0.073%（SE 改善 2.9×）** |
| 据此得出的阈值 | std 0.85% / full 0.85% | **std 0.30% / full 1.20%** |

即：**本机现在的可分辨下限比 9-11 那次低得多**，门的严格性可以收回来一档
（std 0.85% → 0.30%），同时 full 档按规则取 4×std = 1.20%（旧值 0.85% 低于
规则值，源于当时 r11 的单值放松）。

⚠️ 门槛收紧后必须**实测复核门本身可通过**（否则就是把误报换成假失败）：
见下节。

## 落地（三处记录点改齐，杜绝两套真相）
- `tools/bench.py` 的 `PI15_LIMITS`：`std_pct 0.85→0.30`、`full_pct 0.85→1.20`
- `AGENTS.md`：A/A p95 `1.8% → 0.484%`，并写明 n/inner 与两个限值
- `docs/MIGRATION.md`：PI-15 校准值 `+0.85% → std +0.30% / full +1.20%`
- 历史叙事（`docs/log/2026-09-11-资源层与门控校准.md`）**不回溯改写**（铁律 8）

## 复核
`bench.py telemetry-check`（三档 off/std/full，同参 n=25/inner=3）——
判据：`均值 ≤ 限值` 或 `符号不一致（噪声内）` 即通过。

## 复核结果（门槛收紧后门自己可通过）——通过

`bench.py telemetry-check`（三档 off/std/full，同参 **n=25 / inner=3**、window=3000、
config=h264-gpu；off 中位 3.1247s / std 3.1251s / full 3.1272s）：

| 对照 | 均值 | SE | 新限值 | 符号 | 判定 |
|---|---|---|---|---|---|
| std vs off | **+0.040%** | 0.075% | +0.30% | 16/25 **不一致**=噪声内 | 通过 |
| full vs off | **+0.029%** | 0.049% | +1.20% | 20/25 一致 | 通过（均值 ≤ 限值） |

**判定：通过**。两点值得记：

1. 插桩的实际成本（std **+0.040%**、full **+0.029%**）远低于新限值（0.30/1.20），
   也落在 §13.2 的设计目标内（std ≤ +0.1%、full ≤ +1%）——即**本轮遥测新增
   （report v3 心跳 + std 档背压 n/max）没有把 std 档推过设计目标**。
2. std 档符号只有 16/25 一致 → 按 r11 设计判"噪声内"，这正是"可分辨才判失败"
   的预期行为；若把阈值压到 SE 以下（例如 0.1%）就会开始误报。
