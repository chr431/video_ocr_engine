# 2026-10-12 制度重构 S3 · Phase E（渲染化收口 + 负载门禁）

## 后台负载门禁（新增需求 → R-perf-quiet）

- `_measure_lib.assert_machine_quiet`：性能测量启动前采样外部进程负载
  （自身进程树与 Idle 排除，CPU 按单核归一求和折算整机），超阈抛
  BackgroundLoadError 并列元凶清单——立即退出，不浪费整轮。
- **首跑即抓真**：默认 GPU 阈 10% 被 ZCode UI 渲染（31%）+ dwm（28%）打穿
  ——实测校准：GPU 默认 50%（桌面合成常态 20-40% 不算"大负载"，外来计算
  负载才持续 >50%），CPU 维持 15%（≈5 满核/32LP）。
- 接线面：bench（run/diff/ab/telemetry-check）、window_matrix、5 个在树
  探针、bench_hybrid、probe_decode_rates、遥测成本守卫（40% 档——套件内
  实测 25% 会被桌面波动误伤，三连稳后定值）。
- 负测=真负载：起 4 个烧核进程，门禁必须拦（R-guard-negative 实体版）。
- 旧制度"标定/实验期间机器独占，后台任务禁止并行"prose 至此机器化。
