# 2026-09-14 OpenVINO 调优轮：线程/性能提示/BF16/编译缓存四项裁决（现役配置已在最优档）

> 命题（用户）：ORT 移除后，针对 OV 特性再做一轮性能优化。
> 结论：**四项候选全部判死或确认已最优——零产品变更**；预处理融合
> 留作下轮候选。模型级口径（B18/W224 生产形状，中位 of 20）。

## 1. 裁决表

| 候选 | 模型级实测 | 判定 |
|---|---|---|
| 线程档（单流） | t16 23.0ms / t8 30.6ms | 单流 t16 快，但生产=双实例 |
| 线程档（双实例聚合） | 2×t16 49.4 / 2×t12 52.0 / **2×t8 55.0 批/s** | **现役已是 2×t8**（ocr_stage 双实例 half=ot//2），无需改 |
| PERFORMANCE_HINT=THROUGHPUT | 单流 46.4ms（慢 2×）；t8+THP 75.8ms | 判死（为多流限流设计，单流纯亏） |
| HINT_INFERENCE_PRECISION=BF16 | 22.5ms，输出与 f32 **逐位相同**（max\|Δ\|=0） | 判死（Zen4/该模型内核未启用，no-op；零风险亦零收益） |
| CACHE_DIR 编译缓存 | 编译仅 0.21s，缓存省 0.16s/进程（+21KB 盘） | 判死（不值得配置面；对比 TRT 反序列化 0.39~0.44s 量级太小） |

## 2. 复评触发

换 CPU（Intel 混合核→SchedulingCoreType / AMX 机器→INT8/BF16 复评）、
openvino 换代（BF16 内核覆盖变化）、单实例形态出现（线程档语义变）。
